FAQ

How does "no quota" actually work?

MEGA limits transfer bandwidth per IP address. MegaDirect downloads each file once through the server's connection and stores it in a local cache. After that, downloads and streams are served from the cache — so the quota is spent at most once per file, no matter how many people download or watch it.

Which links are supported?

Public file links in any format: mega.nz/file/…#…, mega.nz/#!…!…, links to a file inside a shared folder (/folder/…#…/file/…) — and full folder links: paste /folder/…#… and browse the folder tree right here to pick the files you want.

What can the online player play?

Anything your browser can decode: MP4/H.264, WebM, OGG video, MP3, WAV, FLAC, M4A, OGG/Opus audio and more. Other formats (MKV, AVI, archives…) are still available for direct download.
